# DSH Model Picker

官方 DeepSeek Harness 桌面版的模型选择器插件。源码、构建工具和产物均在本目录；构建不需要 DSH003。运行时使用宿主提供的 React、插槽、模型目录和 MenuSurface。

## 构建与验证

需要 Node.js 22.18+（或 24+）及 npm：

```sh
npm ci --ignore-scripts
npm run verify
npm pack
```

`package-lock.json` 锁定依赖版本。`lib/` 保存已构建产物，桌面版运行不需要安装本目录的开发依赖。npm 包包含运行产物和此说明；本目录还保存源代码、测试及构建配置。

## 安装

将本目录长期保留。在官方桌面版配置 `~/.dsh/profiles/desktop/cordis.patch.yml` 的现有 `insert` 中添加或更新这一行（已有同 id 时不要重复）：

```yaml
- insert:
    - id: dsh-std-model-picker
      name: '/Users/kewen/Documents/DSH-plugins/model-picker/lib/index.js'
```

若使用打包产物，先解压到稳定目录，再将 name 指向其 `lib/index.js`。保留已有替换官方 model 插槽的配置。重载官方桌面版后生效。

### 路由器显示身份（可选）

若把 Harness 的 `deepseek-official` 请求地址改到 Magpie，模型目录的真实提供方 ID 仍是 `deepseek-official`。可在上述插件插入项添加：

```yaml
      config:
        displayProviders:
          deepseek-official:
            name: Magpie
            icon: magpie
```

这只改变模型入口、提供方栏及收藏夹的展示名称/图标（`magpie` 使用 [yetone/magpie](https://github.com/yetone/magpie) 的原始 SVG，收紧留白并继承界面文字颜色；原项目为 MIT 许可）；实际请求提供方、模型 ID、收藏与思考强度存储键均不变。直连 DeepSeek 时移除该映射并重载，避免误标。不要仅凭模型名称猜测路由来源。

## 更新与回退

更新前备份本目录和配置。先在其他目录执行构建、测试，再替换运行产物并重载桌面版；若失败，恢复旧目录或旧配置路径。不要直接删除仍被配置引用的目录。

## 卸载

从 `cordis.patch.yml` 移除插件 id 对应的插入项，并恢复安装时覆盖的官方模型选择器配置，再重载桌面版。确认官方入口恢复后再删除插件文件。卸载不自动删除偏好。

## 兼容与保存位置

构建依赖使用公开发布的 DSH `0.1.7-rc.2` 类型包及 Cordis `4.0.4`。宿主需要提供 `modelDirectories.directoryFor`、会话服务、`conversation.input.model` 插槽、MenuSurface 和模块加载器。此条件不代表任意旧版本或未来版本都兼容；宿主升级后应重新验证。

客户端偏好使用 localStorage：

- `dsh003.model-picker.model-efforts`
- `dsh003.model-picker.favorites`
- `dsh003.model-picker.provider-order`

改插件文件路径不会主动清空这些数据；数据属于当前客户端 origin，不会跨应用或设备同步。会话当前模型由宿主保存，插件保存每个模型接受成功的档位偏好。

## 交互边界修复（2026-09-27）

- 菜单默认在入口上方右对齐；空间不足时收缩高度，上方过窄时改在下方展开，保留列表滚动。
- 拖动取消、失去指针捕获、失焦、关闭面板或换模型均不提交拖动预览；正常松手只提交一次。

- 打开菜单聚焦搜索；上下方向键进入并移动模型行，Escape 关闭并返回入口；键盘调整档位在松键或离焦时提交。
- 部分提供方加载失败时保留可用模型，并显示检查提供方配置的提示。

## 供应商排序（2026-09-27）

首次打开时记住已加载供应商的顺序；宿主重新注册不再改变已有排列，新供应商追加到末尾。按供应商 ID 保存，重名不冲突，暂时不可用的供应商恢复后回到原位。

长按供应商图标 300 毫秒后拖动，细线显示插入位置，松手保存；靠近列表边缘自动滚动。普通点击仍切换供应商，排序不切换供应商或模型。收藏入口固定。Escape 取消排序并保留菜单；失去指针捕获、指针取消、窗口失焦、供应商列表变化或关闭菜单均取消预览。键盘聚焦供应商后可用 Alt + ↑/↓ 排序。

本次构建、类型检查及 34 项测试通过，包含顺序稳定、持久化后重新加载、误触拦截、取消、键盘及边缘滚动。测试使用简化宿主和模拟几何；长按手感和真实桌面视觉仍需重载后验收。

## 后续交互与计算优化（2026-09-27）

- 输入框进入锁定状态时关闭模型卡片、取消未提交的拖动或键盘预览，并拦截新的切换；解锁后由用户重新打开。
- 目录刷新保留正在浏览的供应商；该供应商消失时回退，实际当前模型换到其他供应商时仍跟随。
- 窗口失焦取消档位拖动，即使焦点仍在搜索框；再次操作可正常提交。
- 无模型、无供应商、无收藏、无搜索结果以及加载状态分别显示一条对应提示。
- 缓存供应商排序、收藏汇总及搜索结果，拖动时复用；非收藏视图不汇总收藏，边缘滚动已到尽头时不刷新拖动预览。
